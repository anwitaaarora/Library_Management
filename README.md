# 📚 Library Management System

A CLI-based backend database application built using Python and MySQL to automate library operations, account tracking, and book inventory management.

## 🚀 Key Features

* **Secure Authentication:** Password-protected admin access via CLI.
* **Book Inventory Management:** Complete CRUD operations (Add, Display, Search, Update, Delete) for book records.
* **Multi-Criteria Search:** Query books dynamically by Name, Author, or Genre.
* **Account Records Management:** Register library members with distinct roles, status tracking, and contact emails.
* **Issue & Return System:** Link member accounts to book transactions with automated status checks (`Issued` / `Available`).

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Database:** MySQL
* **Connector:** `mysql-connector-python`
